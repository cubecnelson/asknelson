# general AskNelson

Your API key and chat rooms stay in this browser. Live web + X search are on by default. Attach an image or a PDF with the paperclip, or drag it here. Get a key at console.x.ai — never commit it to the repo.

Settings

Create a key at console.x.ai. It is saved in this browser’s credential store and on this device, together with your chat rooms, so you should not need to enter it again here. Live web and X search are on by default so answers can use the latest sources. The default model, grok-4.7, can also look at attached images (JPEG, PNG, and converted GIF/WebP).
